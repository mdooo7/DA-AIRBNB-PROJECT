# Airbnb Dataset Quality Optimization & Data Cleaning

A targeted data hygiene and optimization project executed inside Google Colab using a rental listings dataset. This project isolates and rectifies real-world data flaws to ensure structural integrity and accurate reporting schema.

## 🛠️ Tech Stack & Tools
- **Environment:** Google Colab
- **Language:** Python
- **Libraries:** Pandas, NumPy

## 🔍 Core Workflow Implemented
1. **Deduplication:** Identified, isolated, and eliminated duplicate rental listings across overlapping identifiers.
2. **Missing Value Treatment:** Implemented systemic imputation strategies for missing listing prices, locations, and host attributes.
3. **Data Integrity Audit:** Cleaned inconsistent categorical text values and adjusted numerical columns to standardized data schemas.

## 📈 Key Technical Outcomes
- **Reliable Schemas:** Converted messy raw data strings into clear analytical tables, resolving duplicate metrics.
- **Analytics Ready:** Transformed irregular listing attributes into distinct categorical parameters for precise reporting.
- **Error Minimization:** Dropped anomalies to completely eliminate statistical bias in downstream business insights.

## 🚀 How to Run the Notebook
1. Download the `.ipynb` file from this repository.
2. Upload it to your **Google Drive**.
3. Open the file via **Google Colab** and run the cells sequentially.
